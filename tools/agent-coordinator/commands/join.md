Join the coordinator. Follow the `join` skill: get the join URL (`$ARGUMENTS` or `COORDINATOR_URL`) and the user's box, then ask the user to run the join command with the `!` prefix so the password is typed in their terminal. If the user hands you the password, use `COORDINATOR_PASSWORD` for the command and never write it to a file or repeat it.
